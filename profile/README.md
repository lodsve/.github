<div align="center">
  <strong>💡 让 Java 工程的起步、开发与构建更容易复用。</strong>

🌐 Lodsve is an open-source toolkit for Java and Spring Boot engineering: reusable components, project templates, and build automation.

## 🧩 项目

| 仓库 | 方向 | 文档 |
| --- | --- | --- |
| [🚀 lodsve-boot](https://github.com/lodsve/lodsve-boot) | Spring Boot 开发套件，提供可组合的 Starter、自动配置和基础组件。 | [Boot 文档](https://docs.lodsve.com/projects/lodsve-boot/) · [Starter 能力](https://docs.lodsve.com/starters/) |
| [🧱 lodsve-maven-archetype](https://github.com/lodsve/lodsve-maven-archetype) | Maven 工程模板，覆盖 Quickstart、MyBatis、Nacos 和 RPC 项目。 | [Maven Archetype 文档](https://docs.lodsve.com/projects/lodsve-maven-archetype/) |
| [🛠️ lodsve-gradle-archetype-plugin](https://github.com/lodsve/lodsve-gradle-archetype-plugin) | 读取本地模板并生成 Gradle 工程，可按团队习惯维护模板。 | [Gradle 插件文档](https://docs.lodsve.com/projects/lodsve-gradle-archetype-plugin/) |
| [🔧 lodsve-maven-plugins](https://github.com/lodsve/lodsve-maven-plugins) | Maven 构建扩展，提供 Java 源码模板生成与 Shade 资源合并能力。 | [Maven Plugins 文档](https://docs.lodsve.com/projects/lodsve-maven-plugins/) |
| [📚 lodsve-docs](https://github.com/lodsve/lodsve-docs) | Lodsve 项目与使用指南的中文文档站。 | [docs.lodsve.com](https://docs.lodsve.com/) |

## 🧭 从这里开始

- ☕ 开发 Spring Boot 应用：阅读[快速开始](https://docs.lodsve.com/getting-started/)并选择所需的 [Starter](https://docs.lodsve.com/starters/)。
- 🧱 初始化 Maven 工程：查看 [Maven Archetype](https://docs.lodsve.com/projects/lodsve-maven-archetype/) 的模板与参数。
- 🛠️ 使用 Gradle 模板：查看 [Gradle Archetype Plugin](https://docs.lodsve.com/projects/lodsve-gradle-archetype-plugin/) 的安装和生成方式。
- 🔧 扩展 Maven 构建：查看 [Maven Plugins](https://docs.lodsve.com/projects/lodsve-maven-plugins/) 文档。

## 🤝 参与 Lodsve

欢迎通过对应仓库的 Issues 🐛 反馈问题，或提交 Pull Request 🌱 改进代码与文档。报告问题时，请附上项目及版本、JDK 和构建工具版本、复现步骤与必要日志；提交前请移除密码、Token 等敏感信息。

贡献指南与反馈方式见[社区与贡献](https://docs.lodsve.com/community/)。
